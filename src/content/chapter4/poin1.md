**Hugging Face Hub** adalah platform utama untuk menemukan, menggunakan, dan berkontribusi terhadap model dan dataset.

Hub menyediakan tempat terpusat bagi komunitas untuk:

* menemukan model dan dataset;
* menggunakan model yang sudah dilatih;
* membagikan model hasil training atau fine-tuning;
* melakukan versioning terhadap model;
* membuat hasil eksperimen lebih reproducible.

Model yang tersedia di Hub tidak hanya berasal dari 🤗 Transformers atau NLP. Terdapat pula model dari berbagai library dan bidang, misalnya:

* **Flair** dan **AllenNLP** untuk NLP;
* **Asteroid** dan **pyannote** untuk speech;
* **timm** untuk computer vision.

Setiap model di Hub di-host sebagai **Git repository**. Hal ini memungkinkan model memiliki versioning sehingga perubahan terhadap model dapat dilacak dan hasilnya lebih mudah direproduksi.

## Keuntungan membagikan model ke Hub

Dengan membagikan model ke Hub:

* model dapat digunakan oleh komunitas;
* pengguna lain tidak perlu melatih model dari awal;
* waktu dan resource komputasi dapat dihemat;
* model hasil training dapat digunakan kembali;
* model dapat dibagikan dan dikembangkan lebih lanjut oleh pengguna lain.

Selain itu, ketika sebuah model dibagikan ke Hub, tersedia **hosted Inference API** untuk model tersebut. Pengguna dapat mencoba model secara langsung dari halaman model menggunakan input yang sesuai.

Model publik di Hub dapat digunakan dan dibagikan secara gratis. Hugging Face juga menyediakan paket berbayar untuk kebutuhan seperti berbagi model secara privat.

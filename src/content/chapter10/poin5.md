Chapter ini membahas empat komponen utama dalam fine-tuning language model:

1. **Chat Templates**

   * Mengatur struktur interaksi antara user dan model.
   * Memastikan format percakapan sesuai dengan model yang digunakan.

2. **Supervised Fine-Tuning**

   * Mengadaptasi pretrained model menggunakan dataset yang sesuai dengan tugas tertentu.

3. **LoRA**

   * Mengurangi jumlah parameter yang perlu dilatih.
   * Menghemat memory ketika melakukan fine-tuning model berukuran besar.

4. **Evaluation**

   * Mengukur kemampuan model setelah fine-tuning.
   * Dapat menggunakan benchmark standar maupun benchmark yang dibuat khusus untuk kebutuhan aplikasi.

Keempat konsep tersebut saling berkaitan dalam proses membangun model yang telah disesuaikan dengan kebutuhan tertentu.
